# Väistä pallot - Selainpeli

"Väistä pallot" on yksinkertainen ja viihdyttävä selaimessa toimiva peli, joka on toteutettu pilvilaskennan kurssin harjoitustyönä.

## Mikä peli on

"Väistä pallot" on 2D-selainpeli, jossa pelaaja ohjaa pelialueen alareunassa olevaa hahmoa. Pelialueen yläosasta putoaa erivärisiä ja -kokoisia palloja. Pelaajan tavoitteena on väistellä putoavia palloja ja pysyä hengissä mahdollisimman pitkään. Peli nopeutuu ja vaikeutuu asteittain ajan kuluessa. Mikäli yksikään pallo osuu pelaajaan, peli päättyy.

## Miten peliä pelataan

1. Aloita peli painamalla **Aloita peli** -painiketta.
2. Liuta hahmoa vasemmalle ja oikealle näppäimistön **vasemmalla ja oikealla nuolinäppäimellä** (`←` ja `→`).
3. Väistä kaikkia ylhäältä putoavia palloja.
4. Pisteet karttuvat sitä mukaa, mitä pidempään säilyt hengissä.
5. Jos pallo osuu hahmoosi, peli päättyy ja näet lopulliset pisteesi.
6. Voit aloittaa uuden pelin välittömästi painamalla **Pelaa uudelleen** -painiketta ilman sivun uudelleenpudotusta tai päivittämistä.

## Miten peli käynnistetään

Peli on toteutettu pelkästään puhtaalla HTML-, CSS- ja JavaScript-koodilla (vanilla JS), eikä se vaadi erillistä taustajärjestelmää, tietokantaa tai ulkoisia kirjastoja.

Voit käynnistää pelin seuraavasti:
1. Lataa tai kloonaa tämä projektikansio koneellesi.
2. Avaa `index.html`-tiedosto missä tahansa nykyaikaisessa verkkoselaimessa (kuten Chrome, Firefox, Edge tai Safari) tuplaklikkaamalla tiedostoa tai avaamalla sen selaimen kautta (`File -> Open File`).
3. Peli on valmis pelattavaksi!
